# SMTUtt — Автономное Android-приложение расписания СПбГМТУ (Корабелка)

Полнофункциональное мобильное приложение для просмотра расписания Санкт-Петербургского государственного морского технического университета (**СПбГМТУ / smtu.ru**).

Приложение **полностью автономно**: парсинг страниц сайта университета происходит прямо на смартфоне (через библиотеку Jsoup и OkHttp). **Никакой сервер на компьютере запускать не нужно!**

---

## Возможности приложения

- **Прямой парсинг сайта СПбГМТУ**:
  - Каталог всех 8 факультетов, курсов 1–6 и 449 учебных групп.
  - Полноценный поиск преподавателей по фамилии (с поддержкой сессий и CSRF-токенов).
  - Парсинг расписания групп и преподавателей: время, недели (верхняя/нижняя), аудитории, корпуса, типы занятий, подгруппы.
- **Офлайн-доступ (Offline-first)**:
  - Все открытые и сохранённые расписания кэшируются в локальную базу данных SQLite (Room).
  - В университете или в метро приложение моментально открывает ваше сохранённое расписание без подключения к интернету.
- **Интеллектуальный фильтр недель**:
  - Переключение «Верхняя неделя» / «Нижняя неделя» / «Все».
- **Интерактивные карточки пар**:
  - Клик по имени преподавателя в карточке пары сразу открывает его личное расписание.
- **Управление избранным**:
  - Быстрый доступ к сохраненным группам и преподавателям, возможность назначить свою основную группу.


## Как собрать и установить на телефон

1. Скачайте и установите **[Android Studio](https://developer.android.com/studio)** (если ещё не установлена).
2. Откройте Android Studio ➔ **Open** ➔ выберите папку `android` (`D:\Python_Projects\SMTUtt\android`).
3. Дождитесь автоматической загрузки библиотек и синхронизации Gradle.

### Способ 1: Собрать готовый APK (без кабеля)
1. В верхнем меню Android Studio выберите:
   **Build** ➔ **Build Bundle(s) / APK(s)** ➔ **Build APK(s)**.
2. После завершения сборки нажмите ссылку **locate** в появившемся уведомлении (файл `app-debug.apk` будет в папке `android/app/build/outputs/apk/debug/`).
3. Отправьте `app-debug.apk` себе на телефон (через Telegram «Избранное» или провод) и установите.

### Способ 2: Запуск прямо из Android Studio по кабелю
1. Включите на телефоне **«Отладку по USB»** (*Настройки ➔ О телефоне ➔ 7 раз на «Номер сборки» ➔ Для разработчиков ➔ Отладка по USB*).
2. Подключите телефон кабелем к ПК.
3. В Android Studio выберите ваш телефон в списке устройств и нажмите зелёную кнопку **Run ▶ (Shift + F10)**. Приложение автоматически соберется и запустится на телефоне.
